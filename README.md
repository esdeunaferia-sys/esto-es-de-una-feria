# Esto es de una feria

Guía de ferias americanas, showrooms y ferias locales de Buenos Aires y Argentina.

- Sitio: https://estoesdeunaferia.com.ar
- Instagram: [@estoesdeunaferia](https://instagram.com/estoesdeunaferia)

Hecho con Expo (React Native + Expo Router) y Supabase, publicado en Vercel.

## Para trabajar en local

```bash
npm install
npx expo start --port 8082   # abrir http://localhost:8082
```

Antes de publicar: `npx tsc --noEmit` y `npx expo lint`.

Todo el detalle del proyecto (datos, diseño, decisiones) está en [CLAUDE.md](CLAUDE.md).
